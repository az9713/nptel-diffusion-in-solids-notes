# House style

Use developed graduate textbook prose, with one move per paragraph. Motivate a
physical question before defining machinery. Define symbols, domains, frames,
units, and terms locally. Show consequential derivation steps, interpret the
result, compute a check, and state where the assumptions bind. No unsupported
"obvious" steps, source narration, slogans, or ornamental equations.

Follow SI units. Use c_i for molar concentration, N_i for mole fraction, J_i for
lattice-frame molar flux, and J_i^V for volume-fixed flux. Keep tracer D_i*,
intrinsic D_i, and interdiffusion D-tilde visibly distinct. Chapter-local notation
is redefined in each chapter. Use numbered equations and figures Chapter.N.

State claim status locally: a definition, constitutive assumption, derivation,
numerical check, empirical observation, or cited extension. Use exact primary
source links and locators when verified. No fabricated page numbers. Timestamp
links beside headings identify the lecture topic, not authorship of extensions.

Examples and code follow an already explained model. State inputs, outputs,
assumptions, errors, and meaningful checks. Synthetic parameters never masquerade
as experimental material data. Exercises mix derivation, diagnosis, inverse
problems, computation, and judgment, with full reasoning in worked solutions.

Use US English and the Oxford comma. Reader controls and indices use concise
system text. Keep production status outside the chapter exposition. Explain
scientifically relevant evidence limits beside the claim they restrict.
