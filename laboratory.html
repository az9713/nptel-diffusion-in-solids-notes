Python laboratory

Install the checked Python dependencies with python -m pip install -r requirements-lock.txt. Run python code_lab.py to list the laboratories, or python code_lab.py 1 to execute Chapter1. The launcher accepts chapter numbers1–28. Run these commands from the extracted repository folder.

Teaching models with stated synthetic inputs and selected attributed source data. They test specified equations and numerical methods; they do not certify material parameters or reproduce proprietary databases.
